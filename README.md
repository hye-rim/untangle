# 줄 풀기 🧶

엉킨 털실 줄을 푸는 두뇌 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)이라 서버가 필요 없다.

- **목표**: 점(털실 공)을 끌어서 옮겨 **줄이 하나도 겹치지 않게** 만든다. 겹친 줄은 빨갛게(깜빡이며) 보이고 위쪽 **겹침** 숫자가 0이 되면 줄이 초록색이 되며 성공.
- **단계**: 1단계는 점 6개, 단계마다 1개씩 늘어 26개까지(5+단계). 단계가 오르면 줄도 촘촘해진다(점 하나당 줄 1.25개 → 최대 1.8개). 시작은 점들을 원 위에 무작위 순서로 늘어놓은 상태라 꽤 엉켜 있다. **모든 판은 반드시 풀 수 있다**(겹치지 않는 그림을 먼저 만들고 점을 섞는다).
- **조작**: 점을 누른 채 끌었다 놓기(폰·마우스). ↩ 되돌리기(Z), 🔄 다시(R), 💡 힌트(H), 🔊 소리(M).
- **힌트**: 정답 그림 자리로 옮기면 겹침이 가장 적어지는 점 하나와 놓을 자리를 분홍색으로 알려 준다. 힌트를 따라가면 점 수만큼 안에 반드시 풀린다.
- **별**: 점을 옮긴 횟수가 기준(점 수의 0.8배 올림) 이하면 ⭐3, 1.6배 이하면 ⭐2, 그 밖은 ⭐1. 힌트를 쓰면 최대 ⭐2. (되돌리기는 이동 횟수를 줄이지 않는다.)
- **저장**: `untangleBest`(가장 높이 푼 단계, 로비에 표시), `untangleMuted`.
- 연습(`?tutorial=1`)은 점 8개 판으로 하고 저장하지 않는다.

규칙·판 만들기·힌트는 `logic.js`(`LOGIC_UT`, 화면 없이 Node 로 시험), 화면·입력·소리는 `game.js`. 시험은 `node --test`(디렉터리): `test/logic.test.js`(선분 겹침 판정(끝점 공유·평행·포개짐), 겹침 짝 세기, 단계별 점 수, 30단계×시드 3개의 판이 풀 수 있는지(정답 그림에 겹침 0·시작은 엉킴·연결됨·줄 중복 없음·좌표 범위), 점 사이 간격, 같은 시드는 같은 판, 줄 밀도, 힌트를 따라가면 점 수 안에 풀림, 힌트가 최선의 점을 고름, 별 계산).
